# Format Lokalisasi: JSON, ARB, YAML, PO/POT, Android XML (beta)

- **Ekstensi:** `.json`, `.arb`, `.yaml`, `.yml`, `.po`, `.pot`, Android `strings.xml` (`.xml` dengan akar `<resources>`).
- **Dependensi:** stdlib untuk JSON/ARB/PO/Android XML; extra `[yaml]` (`PyYAML`) untuk YAML.

## Perilaku per format
- **JSON:** hanya nilai string yang diterjemahkan; kunci, angka, boolean, null, urutan kunci, dan indentasi dipertahankan. QA memverifikasi struktur kunci hasil identik dengan sumber.
- **ARB (Flutter):** melewatkan seluruh kunci metadata berawalan `@` (`@@locale`, `@key`), menyertakan `description` sebagai konteks segmen, dan menyetel `@@locale` menjadi `"id"` saat `--keep-lang` tidak aktif.
- **YAML:** mengganti node skalar string secara in-place menggunakan posisi node PyYAML; komentar dan kunci tetap utuh. QA memverifikasi struktur kunci dengan `yaml.safe_load`.
- **PO / POT (Gettext):** mengekstrak `msgid` / `msgid_plural` dan menulis ke `msgstr` / `msgstr[N]`; menyetel `Language: id` dan `Plural-Forms: nplurals=1; plural=0;` pada header bila ada.
- **Android `strings.xml`:** menerjemahkan `<string>`, `<string-array>/<item>`, dan `<plurals>/<item>`; melewatkan entri `translatable="false"`; menjaga tag inline (`<b>`, `<xliff:g>`) dan menerapkan escape Android (`\'`, `\"`, `\@`, `\?`, entitas XML).
