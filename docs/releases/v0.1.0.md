# Catatan Rilis v0.1.0 (Draf Persiapan)

> **Status:** draf persiapan rilis. Tag git `v0.1.0` dan berkas `LICENSE` **belum dibuat** —
> menunggu keputusan dan eksekusi pemilik repositori (lihat [release-checklist.md](../release-checklist.md)
> dan [license-decision.md](../license-decision.md)).

## Ringkasan
`v0.1.0` adalah rilis perdana `terjemahan-id` (`id-translate`): kombinasi aturan tunggal (`AGENTS.md`),
skill sesuai spesifikasi `agentskills.io` (`skills/translate-id/`), dan CLI Python deterministik agar
AI agent menerjemahkan dokumen ke Bahasa Indonesia secara aman tanpa menimpa file asli.

## Yang baru di v0.1.0
- **CLI deterministik `id-translate`** (`init`, `inspect`, `extract`, `batch`, `apply`, `compare`,
  `qa`, `verify`, `glossary-scan`, `--dry-run`, exit code `0`–`6`).
- **Invarian keselamatan teruji:** penulisan eksklusif (`open(..., "xb")`), folder hasil baru
  `hasil-terjemahan/<nama>_ID_<waktu>/`, verifikasi SHA-256 sumber dan hasil, penolakan PDF
  terenkripsi, Office OLE terenkripsi, dan EPUB ber-DRM.
- **Kontrak segmen JSONL (`id-translate/segments@1`)** dengan masking token pelindung (`⟦P1⟧`,
  `⟦S1⟧…⟦/S1⟧`), batching berbasis estimasi token, resume dari checkpoint, dan translation memory JSONL.
- **Dukungan format (status `beta`):** Markdown, TXT, SRT, WebVTT, JSON, ARB, YAML (`[yaml]`),
  PO/POT, Android `strings.xml`, DOCX/PPTX/XLSX (`[office]`), HTML, EPUB, serta prototipe PDF
  di balik antarmuka `PdfEngine` (backend opsional PyMuPDF `[pdf]`).
- **Skill & rules lintas agent:** `AGENTS.md` sumber tunggal (termasuk aturan Git), penunjuk tipis
  `CLAUDE.md`, `GEMINI.md`, `.cursor/rules/translate-id.mdc`, `.github/copilot-instructions.md`,
  dan validator `scripts/validate_skill.py`.
- **Evaluasi & CI:** 18 kasus evaluasi otomatis (`evals/run_evals.py`), laporan nyata `docs/evals.md`,
  workflow GitHub Actions, `THIRD_PARTY_NOTICES.md`, dan peta klaim `docs/claims.md`.

## Catatan penting sebelum memakai
- **Lisensi PyMuPDF:** extra `[pdf]` memakai PyMuPDF yang berlisensi ganda **GNU AGPL-3.0** atau
  **lisensi komersial Artifex** (opsional, tidak di-vendor). Pengguna bertanggung jawab mematuhi
  lisensi PyMuPDF sendiri. Lihat [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).
- **Keterbatasan:** lihat [docs/known-issues.md](../known-issues.md).
